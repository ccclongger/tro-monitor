⚠️ 本案最易被低估
  • emoji company GmbH ≠ Unicode / Apple / Google 的 emoji。Emoji Company 是德国 IP 运营公司，不拥有 Unicode emoji 的版权——Unicode 的 emoji 字形设计是各家自己做的，公共领域的 😀 这类符号本身不能被任何一家公司垄断。
  • 但它确实在第 9 / 16 / 25 / 28 / 41 等类持有大量 EMOJI 文字及图形商标。主诉逻辑是：把「Emoji」这个词或黄脸表情图样当作品牌、商品名称或品类描述用在商品标题、包装、详情页上，构成商标性使用。
  • 常见踩雷情形：标题堆「emoji」关键词引流、把黄脸表情印在手机壳 / T恤 / 贴纸 / 毛绒玩具上并标注「Emoji」字样。判断标准不是「是不是表情包」，而是「是否商标性使用」。
✅ 排查建议
  • 标题/属性词排查：Emoji / EMOJI / 表情 / 表情包 / Emoticons 作为品牌词或品类描述出现即需处理。
  • 图形排查：黄脸圆脸表情作为主视觉或品牌标识使用（带 Emoji 字样、成套系列化）需重点排查；纯 Unicode 公共符号无文字标注的，风险显著更低。
  • 反向安全区：仅使用 Unicode 标准 emoji 字形、不带任何 EMOJI 文字标识、不将其作为品牌或商品名称——这类使用通常不在本案维权范围内，但仍建议做 FTO 复核。
